# Register Hive Form – HTML + JavaScript Template

This project provides a ready-made HTML form and accompanying JavaScript to register a beehive into your Supabase backend using Netlify or static site hosting.

---

## 🌿 Features

- Clean, accessible HTML form
- Automatically hides "Other" input fields unless selected
- Auto-populates apiary dropdown from Supabase
- Uploads hive photo to Supabase Storage (if included)
- Posts full payload to `hives` table in Supabase
- Redirects to dashboard after success
- Styled to match your beekeeping platform
